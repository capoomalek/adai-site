# Polices de la charte ADAI

| Police | Rôle | Statut |
|---|---|---|
| Bebas Neue | sous-titres | Incluse via le paquet npm `@fontsource/bebas-neue` |
| Glacial Indifference | corps de texte | Incluse ici (licence SIL OFL, voir OFL-GlacialIndifference.txt) |
| Sugo Classic | titres | **À ajouter** : déposer `SugoClassic.woff2` dans ce dossier, après avoir vérifié que la licence autorise l'usage web |

Tant que Sugo Classic manque, les titres s'affichent en Bebas Neue.
Pour convertir un .ttf/.otf en .woff2 : https://transfonter.org
